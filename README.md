# CUDA Ray Tracer

Рейтрейсер, написанный на C++ с CUDA в рамках л/р. Запускается через консоль, рисует сцену из сфер на GPU и сохраняет результат в BMP-формате.

---

## Что умеет

- Рассчитывает освещение по модели Фонга (ambient + diffuse + specular)
- Считает тени от всех объектов сцены
- Отражения с затуханием (до 4 отскоков луча)
- Сферы расставляются по кругу автоматически, радиус кольца подбирается так, чтобы они не касались друг друга
- Пол - отдельная большая сфера, не считается в лимит
- До 2 источников света с разным цветом и интенсивностью
- Гамма-коррекция (sqrt) перед записью
- Вывод в BMP без сторонних библиотек

## Как пользоваться

Запускается через консоль. Программа задаёт вопросы по очереди:

```
CUDA Ray Tracer

Number of spheres (1-10): 6
Number of light sources (1-2): 2
Image width  (800-1920): 1280
Image height (600-1080): 720
Output filename (without extension): scene_01

```

После этого начинается рендер. В конце выведет время GPU и сохранит файл рядом с exe:

```
Rendering 1280x720, 6 spheres, 2 light(s)...
GPU render time: 12.47 ms
Saved: scene_01.bmp
```

## Как устроена сцена

**Камера** смотрит сверху-сбоку на центр сцены. Позиция фиксированная, угол обзора 60°.

**Сферы** встают по кругу. Радиус кольца считается автоматически:

```
R = max(3.0, (sphere_radius + gap/2) / sin(π / n))
```

Минимальный зазор между поверхностями - 0.4 единицы. При одной сфере она встаёт в центр.

**Пол** - сфера радиусом 50, центр на Y = −51. Серая, слабо отражающая.

**Источники света:**
- Первый: белый, интенсивность 1.0, позиция (2, 4, −3)
- Второй: синеватый, интенсивность 0.7, позиция (−3, 3, 2)

**Материалы сфер** задаются по порядку из встроенного набора (10 вариантов). Параметры - цвет, specular (глянец), reflective (отражательная способность):

| № | Цвет | Specular | Reflective |
|---|------|----------|------------|
| 1 | Красный | 200 | 0.30 |
| 2 | Синий | 500 | 0.60 |
| 3 | Зелёный | 50 | 0.10 |
| 4 | Жёлтый | 300 | 0.50 |
| 5 | Розовый | 150 | 0.40 |
| 6 | Бирюзовый | 100 | 0.20 |
| 7 | Оранжевый | 400 | 0.50 |
| 8 | Фиолетовый | 250 | 0.35 |
| 9 | Белый | 600 | 0.80 |
| 10 | Мятный | 120 | 0.25 |

## Структура кода

```
main.cu
├── Vec3          - векторная математика (dot, cross, norm, len)
├── Ray           - луч (origin + dir, метод at(t))
├── Sphere        - сфера (центр, радиус, цвет, specular, reflective)
├── Light         - источник света (позиция, цвет, интенсивность)
├── hitSphere()   - пересечение луча со сферой (квадратное уравнение)
├── computeLighting() - модель Фонга + проверка теней
├── traceRay()    - трассировка с отражениями (до 4 отскоков)
├── renderKernel  - GPU-ядро, один тред = один пиксель
├── saveBMP()     - запись файла без библиотек
├── readInt()     - ввод с валидацией диапазона
└── main()        - ввод параметров, генерация сцены, запуск
```
