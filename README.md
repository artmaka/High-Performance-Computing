# Лабораторная работа | High-Performance-Computing

## Перемножение матриц с использованием CPU и GPU

---
## Постановка задачи

Необходимо реализовать алгоритм перемножения двух квадратных матриц размером от 100×100 до 2000×2000.

Требуется:

* реализовать вычисления на CPU
* реализовать вычисления на GPU с использованием CUDA
* провести сравнение времени выполнения
* определить ускорение

---

## Теоретические сведения

Перемножение матриц является вычислительно сложной задачей с временной сложностью O(N³).
Каждый элемент результирующей матрицы вычисляется по формуле:

C[i][j] = Σ A[i][k] * B[k][j]

Данная задача хорошо подходит для распараллеливания, так как вычисление каждого элемента результирующей матрицы может выполняться независимо.

---

## Реализация

### Реализация на CPU

На ЦП использован классический алгоритм с тремя вложенными циклами.

---

### 4.2 Реализация на GPU

На ГП реализован параллельный алгоритм с использованием CUDA.

Каждый поток:

* вычисляет один элемент результирующей матрицы

Использована оптимизация Shared Memory (tile-подход)

---

## Измерение времени

Для измерения времени использованы:

* CPU: библиотека `chrono`
* GPU: `cudaEvent`

Использование `cudaEvent` необходимо, так как CUDA выполняет операции асинхронно.

---

## Проверка корректности

Корректность вычислений проверялась с помощью контрольной суммы элементов результирующей матрицы.

---

## Эксперименты

Вычисления проводились для размеров:

100, 200, 300, …, 2000

Для каждого размера измерялись:

* время выполнения на CPU
* время выполнения на GPU
* ускорение

## Анализ результатов

В ходе экспериментов было установлено:

* CPU показывает квадратичный рост времени с увеличением размера
* GPU значительно быстрее CPU на больших размерах
* ускорение увеличивается с ростом N

На малых размерах GPU может уступать CPU из-за накладных расходов.

---

## Заключение

Задача перемножения матриц эффективно распараллеливается и является хорошим примером применения GPU.
