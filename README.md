# Сумма элементов вектора (CPU | GPU, CUDA) | High-Performance-Computing

## Описание задачи

Целью лабораторной работы является реализация алгоритма суммирования элементов вектора на CPU и GPU с использованием технологии CUDA, а также сравнение их производительности.

Входные данные:
Вектор размером от **1 000 до 1 000 000** элементов.

Выходные данные:

* Сумма элементов вектора
* Время выполнения на CPU и GPU
* Ускорение (speedup)

---

## Реализация

### CPU версия

На CPU реализован простой последовательный алгоритм:

* Перебор всех элементов вектора
* Накопление суммы

**Сложность:** O(N)

---

### GPU версия (CUDA)

Реализован параллельный алгоритм с использованием:

* CUDA kernels
* Разбиения на блоки и потоки
* **Параллельной редукции (reduction)**
* Shared memory

#### Основные идеи:

* Каждый поток суммирует часть элементов
* Частичные суммы сохраняются в shared memory
* Выполняется редукция внутри блока
* Итоговая сумма собирается через `atomicAdd`

---

## Измерение времени

* CPU: `std::chrono`
* GPU: `cudaEvent`

Использование `cudaEvent` позволяет корректно измерять время выполнения на GPU с учётом асинхронного выполнения CUDA.

---

## Проверка корректности

Корректность проверяется через сравнение суммы элементов, полученной на CPU и GPU.

---

## Эксперименты

Проведены вычисления для размеров:

1000, 2000, 3000, ..., 1 000 000

Для каждого размера измеряются:

* время CPU
* время GPU
* ускорение

Результаты вычислений приведены в выводе vectorsum.cu
